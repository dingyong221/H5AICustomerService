# Web 试运行受控发布例外方案

> 状态：待审设计，**不是发布许可**。适用于 `h5cs.1rying.com` 的平台运营后台、商家后台和消费者 AI 客服；WorkBuddy 继续暂停。

本文供项目负责人决定：在离机备份和完整灾难恢复暂缓时，是否允许一个有明确边界的 Web 试运行。现有 `production` 门禁及 `productionBusinessReadiness=false` 保持不变。合并本文档不运行迁移、不修改服务器、不开放业务路由，也不把试运行称为正式生产就绪。

## 当前事实和例外范围

- 已批准在现有服务器运行本项目专用 MySQL；这项批准没有接受单机或无离机备份的数据损失风险。生产库尚未执行 12 项业务迁移，公网 `/ops` 仍不可用。
- 隔离 Staging 已验证运营开通、商家发布、消费者对话、两商户页面隔离、真实千问调用，以及同机备份恢复和应用回滚。Staging 结果不能代替新镜像的复验或生产数据恢复。
- PR #7 已修复旧候选镜像所用的 Next.js 版本并合并；旧 `70ffb05` 镜像不得上线。必须从合并后的干净提交重新生成五个不可变镜像，验证摘要、签名和来源，并以相同摘要重跑 Staging。

拟议例外只针对以下原有生产门禁：离机备份、binlog 归档、时间点恢复演练、生产容量告警和第二名人工审批人。它们在正式生产证据中继续保持 `false`，不能用本机备份、空库恢复或同一人的两个身份冒充通过。其余门禁不因本方案放宽，包括高危/严重依赖漏洞、密钥泄露、商户隔离、真实模型、有效 TLS、私网数据库、可回退制品、发布审计和公开端口限制。

## 建议的试运行边界

1. 单独定义 `controlledWebPilot` 状态和证据，不修改现有 `production` 命令的判定，也不把 `productionBusinessReadiness` 置为 `true`。对外及后台显著标识“试运行”，不得宣称具备生产级数据恢复承诺。
2. 初次试运行限定项目负责人控制的商家及测试数据。未完成离机备份和风险接受前，不邀请真实商家上传不可替代的商品资料、客户个人信息或真实交易记录；消费者入口可用于受控演示，不作正式客户承诺。
3. 生产库迁移前先做只读清单、迁移计划哈希核对、磁盘容量检查和本机可恢复快照。对首次迁移、可能丢失数据的单机风险、维护窗口及公网切流，分别取得项目负责人明确的当次授权。本文档的批准不替代这些授权。
4. 五个新镜像需通过仓库检查、供应链校验和相同摘要的 Staging 核心 E2E、租户隔离、真实千问、异步任务、文件处理及回滚测试。切流前验证证书、续期、反向代理路径、MCP/OAuth/Skill 拒绝策略，以及生产路由的可回退配置。
5. 试运行期间只允许公网 80/443；22 保持工作站当前出口 `/32`。MySQL、容器内部端口和监控端口不得公开。保留受限访问日志和人工可见的错误/容量检查；若没有实时告警送达，明确安排人工巡检频率和负责人，不能写成“告警已通过”。
6. 给试运行设定结束日期、数据保留和退出条件。出现数据损坏、跨商户可见、密钥泄露、真实模型不可用且无安全降级、证书失效或回滚失败时立即停止新增使用并按 Runbook 回退；数据库结构不可逆时不得盲目回滚旧应用。

## 审批与执行顺序

| 阶段 | 所需证据或决定 | 未满足时的动作 |
| --- | --- | --- |
| 方案评审 | 项目负责人确认试运行边界、允许的数据类型、单机数据损失风险和例外到期日 | 只保留设计，不执行迁移或切流 |
| 候选构建 | 合并提交对应的五个签名不可变摘要、依赖审计、SBOM、来源证明 | 停止发布，旧镜像不得替代 |
| Staging 复验 | 相同摘要的核心业务、租户隔离、真实模型、任务和回滚证据 | 修复后重新构建并复验 |
| 生产准备 | 当次迁移授权、空库或既有数据清单、容量、恢复点、受限配置、证书、人工巡检和回退值班人 | 不运行迁移，不开放 `/ops` |
| 受控切流 | 项目负责人再次确认试运行范围、维护窗口和公网切流；记录部署摘要与验证结果 | 维持 503，继续 Staging |
| 扩大或转正 | 离机备份、binlog PITR、隔离恢复、容量告警、正式审批等原门禁全部通过 | 不扩大真实用户和数据范围，保持 `productionBusinessReadiness=false` |

实现时应新增一个独立的、默认拒绝的试运行证据模式及自动化校验。例外字段只能记录“已获接受的风险、批准人、时间、到期日和证据引用”，不能把未完成项改写为 `true`。门禁实现、证据模板和 Runbook 应通过单独 PR 审查；只有上述当次授权到位，才可在服务器执行迁移、部署和切流。
