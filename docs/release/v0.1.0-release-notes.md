# v0.1.0 仓库标准版本说明

发布日期：2026-09-22

## 版本结论

`v0.1.0` 是本项目首个**仓库标准版本**：固定源码可在 Node.js 24 / pnpm 11.19.0 下通过依赖审计、Compose 解析、格式、Lint、类型、测试、构建、Shell 语法、秘密扫描、SBOM 与源码哈希门禁。

它不是生产业务发布。`h5cs.1rying.com` 仍只提供 HTTP 维护健康入口；缺少真实外部依赖时，所有敏感运行时保持失败关闭。

## 本版本范围

- MySQL InnoDB 作为唯一业务事实存储，包含授权、平台会话、onboarding、客服草稿、Release、活动版本、幂等、Outbox 与审计结构。
- WorkBuddy/OAuth/MCP 边界明确区分平台登录、外部身份、商家 Membership、Connector consent 和平台 Access Token。
- Merchant Web 提供严格信封解析的授权与管理客户端；Consumer H5 提供公开客服、会话、消息与终态轮询客户端。
- 发布 Compose 只接受不可变 digest，业务端口仅绑定 loopback；发布/回滚 Runbook 明确 previous→candidate→previous 证据。
