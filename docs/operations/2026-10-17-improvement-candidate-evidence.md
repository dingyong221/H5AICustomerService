## CI 类型与升级锁修复

`f8eafe7` 的 [CI 38956378444](https://github.com/dingyong221/H5AICustomerService/actions/runs/38956378444) 已实际通过修正后的 Nginx 断言及三种路径模式的浏览器闭环，但质量任务在 API 集成测试的 TypeScript 检查失败，新增升级探针也未通过。该提交不计为统一验收成功。
