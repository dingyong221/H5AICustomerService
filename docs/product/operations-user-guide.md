# 运营后台使用指南

运营后台用于开通和管理商家、了解平台使用情况、排查异常及导出汇总报表。它与商家后台是两个独立的身份入口；运营人员不需要、也不应使用商家的密码查看运营统计。

本文对应运营增强分支功能；部署后使用下列入口。当前线上是否已更新，以对应发布记录为准。

## 登录与首页

打开[运营后台](https://h5cs.1rying.com/ops)，使用原运营账号登录。首页上方显示当前全部商家和客服数量；下方选择今天、近 7 天、近 30 天、近 90 天，或填写开始与结束日期，点击“应用筛选”。日期均按北京时间计算，最多查询 93 天。

“已启用商家”表示账号已启用，不等于商家今天在线。“期间使用商家”表示所选期间至少发送过一条消费者问句。新会话、问句数、失败数可以帮助判断是否有人使用；它们不能直接证明消费者满意或产生订单。

页面显示“统计暂不可用”时请稍后刷新，不要把它当作没有数据。当天的数据只统计到查询时刻。点击页面下方“查看统计口径与数据边界”可以核对每个指标的含义。

## 开通与查找商家

电脑端采用左侧菜单、右侧内容的布局。点击“商家运营”“数据报表”或“运行管理”可展开或收起二级菜单；进入页面后，对应分组会自动展开并高亮当前位置。手机端点击“展开菜单”选择功能，点击链接后菜单会收起；也可点击“收起菜单”或按 Esc 收起。

新商家仍从“商家开通”创建，复制一次性领取链接给负责人。负责人领取后，使用自己的商家账号配置和发布客服。不要把运营账号密码发给商家。

已有商家从左侧“商家运营 → 商家管理”进入。可按商家名称或完整 ID 查找，按等待领取、已启用、已暂停筛选，或只看期内有／无消费者问句的商家。排序可选最近开通、问句最多、新会话最多或失败问句最多。结果超过一页时使用“上一页／下一页”；页面总数是全部匹配数，不是当前页的条数。

点击商家名称或“查看详情”，可以看到它的当前状态、开通时间、最近消费者问句、每日用量、客服使用及改进复测情况。通过这里的商家后台链接进入配置时，仍需商家账号登录，运营权限不会变成商家权限。

## 领取与暂停处理

等待领取的商家可以重新签发领取链接，旧链接会立即失效。先确认对方确实没有领取，再重新签发，避免多个链接交叉发送。

需要暂停时，进入商家详情，展开“暂停此商家”，填写至少 5 个字符的原因，核对商家编号并勾选影响确认，再提交。暂停会阻断该商家的公开客服、已有咨询及管理访问，但不会删除资料、固定消费者链接或历史用量。解除原因后，按相同方式填写恢复原因并确认恢复。

如果提示操作结果暂无法确认，请刷新详情和首页审计记录后再判断，不要连续重复提交。

## 商家账号与密码

进入“商家运营 → 商家管理 → 商家详情”，在“账号与密码管理”查看该商家的登录账号。固定账号以 `m_` 开头，可复制给负责人登录；原手机号和当前密码仍可登录。同一个账号可能管理多个商家，页面会列出关联商家的名称和编号。尚未领取的商家没有密码账号，应先发送领取链接。

原密码不以明文保存，不能查看或找回。需要重置时，展开“重置此账号密码”，填写两次一致的 12–128 位新密码，选择“忘记密码”等原因，再填写当前运营账号密码。核对全部关联商家并勾选确认后，点击“确认重置商家密码”。重置原因只允许选择固定选项，不要在其他操作原因或备注中填写密码。

成功后，该账号的全部旧商家登录会话失效，原密码不再可用。通过安全渠道将新密码告知负责人；页面不回显新密码。重置不改变商家启用／暂停状态，不删除资料，也不影响消费者正在使用的已发布客服。共享同一账号的其他商家也需要使用新密码重新登录。

若提示账号或关联商家已变化，刷新后重新核对。若无法确认结果，先查审计记录和实际登录结果，不要连续重复重置。

## 查看和导出报表

左侧“数据报表”提供五种视图，也可以使用报表内容区的标签切换。左侧菜单进入的是全平台报表；从商家详情进入则保留该商家范围。

| 报表       | 适合解决的问题                                                       |
| ---------- | -------------------------------------------------------------------- |
| 每日使用   | 哪几天会话与问句增长，完成、失败和未终结分别多少。                   |
| 商家使用   | 哪些商家已开始使用，哪些商家可能需要资料配置或发布指导。             |
| 客服使用   | 同一商家多个客服各自的问句、会话和处理耗时。                         |
| 改进与复测 | 商家是否创建改进任务、完成复测和评审，以及当前任务版本是否已经发布。 |
| 异常分布   | 消费者问句及后台任务分别出现哪些错误码，优先排查哪类异常。           |

从商家详情点击“查看此商家报表与导出”，会自动带入商家 ID；在报表筛选中清空 ID 可恢复全平台范围。商家使用报表还可以按名称、状态和使用情况筛选。

点击“导出本报表 CSV”或商家列表的“导出筛选结果 CSV”。导出的是当前筛选的完整结果，不只当前一页。最多 5,000 条；超过上限时按商家 ID、名称或状态缩小范围。导出不包含手机号、密码、令牌和咨询正文，仍请妥善保管商家名称及使用数据。

## 如何理解异常数字

会话创建在前一天、消费者今天继续提问时，今天会有问句，但不一定有新会话。这不是漏统计。处理状态变化后，问句接收日期对应的完成／失败数也会更新。

完成率只说明技术处理是否完成，不能当作答案准确率或真实解决率。失败问句和失败后台任务可能对应同一次故障，不要把两项相加当作失败用户数。平均处理耗时包含排队时间，也不是模型首字速度。

从公开 H5 做的测试咨询会进入使用报表；商家发布前试聊、资料助手和独立复测不计入消费者问句。当前没有满意度、订单、成交额、Token 或模型费用数据，相关能力需接入相应事件或账单后再统计。
