# H5 AI 客服 Web 版使用指南

适用日期：2026 年 10 月 6 日。适用范围：当前受控 Web 测试版。

这份指南帮助平台运营者和商家走通完整流程：开通商家后台、填写业务资料、试聊、发布，再把消费者链接发给客户。目前 WorkBuddy 尚未接通，不属于本指南的可用操作入口。

核心逻辑是：**平台开通商家 → 负责人领取后台 → 商家创建客服草稿 → 核对资料并试聊 → 明确发布 → 消费者打开 H5 对话。**

## 一 先分清角色和链接

| 入口                                        | 谁使用               | 用途                                     | 是否可以发给消费者           |
| ------------------------------------------- | -------------------- | ---------------------------------------- | ---------------------------- |
| [平台运营后台](https://h5cs.1rying.com/ops) | 平台运营者           | 开通商家、查状态、维护行业引导、处理异常 | 不可以                       |
| 商家后台领取链接                            | 指定商家负责人       | 首次领取后台并建立账号关联               | 不可以；一次性链接须私下交付 |
| 商家管理后台链接                            | 已获授权的商家人员   | 登录后配置客服、试聊、发布、查看咨询     | 不可以                       |
| 消费者 H5 链接或二维码                      | 咨询产品和服务的客户 | 与已发布的 AI 客服对话                   | 可以，在确认可用后分享       |

平台运营账号和商家账号不同。运营账号是 `admin`；商家使用自己领取后台时填写的手机号和密码。运营者即使看到商家管理链接，也不会因此自动取得商家账号权限。

创建商家只是开通一个管理空间，不代表已经生成或发布 AI 客服。

每个商家的管理地址为 `https://h5cs.1rying.com/商家ID`。侧栏各功能进入该商家的独立页面，地址均带商家 ID。服务器每次都会核对账号的商家权限，修改地址不能进入其他商家的管理空间。

## 二 平台运营者开通商家

1. 打开[平台运营后台](https://h5cs.1rying.com/ops)。如跳到登录页，使用运营账号和管理员密码登录。
2. 找到 **生成商家后台领取链接** 区域。
3. 在 **商家名称** 填写容易辨认的名称，例如“示例家电清洗测试店”。首次体验建议使用独立测试商家。
4. 点击 **创建商家并生成领取链接**。
5. 看到“已创建，等待商家领取”后，点击 **复制领取链接**，私下交给实际负责人。注意页面显示的“有效期至”时间。

请复制按钮提供的完整链接，不要删掉其中任何部分。生成后先复制再离开页面，不要把领取链接当成长期登录地址，也不要群发。

如果链接丢失或过期，在“最近商家”中找到处于“等待领取”的商家；也可用 **按名称或完整商家 ID 查找** 搜索。勾选 **我确认旧领取链接将立即失效**，再点击 **重新签发领取链接**。新链接生成后，旧链接立即失效。不要为找回链接重复创建同一个商家。

## 三 商家负责人领取后台

1. 打开运营者发来的完整领取链接。
2. 填写 **负责人手机号**。
3. 首次使用本平台时，在 **平台登录密码（至少 12 位）** 中设置自己的密码。如果该手机号已有本平台账号，应使用原账号密码，而不是另设一个密码。
4. 点击 **领取商家后台**。
5. 成功后进入当前商家的“商家工作台”。把此时的商家工作台地址加入收藏，并妥善保存手机号和密码。

领取成功后不再使用一次性领取链接。以后可打开收藏的商家后台地址；账号仅关联一个商家时，也可进入[商家登录页](https://h5cs.1rying.com/console/account/login)。如账号关联多个商家，请使用运营后台提供的目标商家管理链接；通用登录页目前没有商家选择器，不能在那里直接选择商家。

如果你自己测试，可以同时扮演运营者和商家负责人；两类账号仍然独立，不要把运营密码作为商家密码。

## 四 填写资料并创建客服草稿

点击侧栏 **客服草稿**，进入 `商家ID/drafts` 页面，在 **客服基础资料** 中填写：

| 字段             | 应填写什么                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| 客服名称         | 对消费者展示的名称，例如“示例清洗店客服”                                 |
| 行业资料引导     | 可选。选择适合的行业模板，查看需要准备哪些资料；没有合适模板时可手动填写 |
| 细分行业         | 具体业务，例如“家用空调上门清洗”，不要只写“服务业”                       |
| 业务范围         | 服务地区、营业时间、服务对象、能做和不能做的业务                         |
| 商品或服务资料   | 产品特点、服务项目、流程、注意事项及常见问答                             |
| 价格与条件       | 价格、计价单位、适用条件、额外费用；没有公开价格时写“价格需联系商家确认” |
| 优惠与售卖策略   | 活动内容、期限、条件、能否叠加；没有活动时写“目前无优惠活动”             |
| 欢迎语           | 消费者进入客服页面时看到的问候语                                         |
| 资料不足时的回复 | 无法从现有资料确定答案时的回应，例如“这项信息尚未确认，请联系商家核实”   |

电商零售预设会填入通用选购和购物流程知识，但不代表商家销售全部品类，也不含商家的实际价格、库存或活动。其他行业模板提供资料准备提示。价格、优惠、库存和承诺必须由商家提供并核对。

每个字段旁都可以点击 **帮我写**，用简短描述生成多个文案备选。核对后选择 **填入此字段**，这只修改表单，仍需点击创建或保存。具体操作见下文“客服资料填写助手”。

当前最小使用流程采用文本资料。FAQ 可以按“问／答”格式写入 **商品或服务资料**，例如：

```text
以下仅为虚构测试内容，正式使用前须替换并核实。

服务：家用壁挂式空调清洗。
问：可以当天上门吗？
答：需要先联系商家确认排期，不承诺当天上门。
问：支持维修吗？
答：当前只提供清洗，不提供维修。
```

填好后点击 **创建客服草稿**。成功后会显示绿色结果区域，点击 **进入客服配置、试聊和发布**，或从下方 **已创建的客服** 列表点击客服名称。若尚未创建成功，请先查看必填资料提示或错误信息。

## 五 核对资料并进行发布前试聊

### 核对并确认

1. 查看详情页顶部的“草稿修订”和全部资料。
2. 如有错误，在 **修订草稿** 区域修改，再点击 **保存草稿修订**。
3. 保存后按提示点击 **重新打开并核对新修订**，不要停留在旧修订页面继续操作。
4. 点击侧栏 **知识库**，进入当前客服的知识资料页。在 **商家确认** 区域勾选“我已逐项核对以上资料……”并点击 **确认当前草稿资料**。

确认资料只表示认可这些业务信息，不会自动开放消费者客服。

### 试聊并检查答案

1. 点击侧栏 **测试与发布**，进入当前客服的发布页。在 **发布前试聊** 区域的 **试聊问题** 中输入问题。
2. 点击 **发送测试问题**，查看“AI 试聊回答”。
3. 建议至少检查以下问题：

   - 你们提供什么服务？
   - 价格是多少，有哪些条件？
   - 有优惠吗，是否可以叠加？
   - 一个资料中没有答案的问题，例如“明天上午一定能上门吗？”

4. 答案不准确时，先补充或修订资料并保存，重新打开最新修订、确认资料，再试聊。

试聊会把当前已保存的草稿资料和问题发送至阿里云千问，但不会发布客服。尚未点击“保存草稿修订”的输入内容不是服务端当前草稿，不能用来判断试聊是否采用了新资料。

当前为受控测试版，优先使用测试业务资料，不要输入不必要的个人隐私或秘密凭据。试聊回答只是验证参考，不能代替商家核对。

## 六 正式发布客服并分享给消费者

1. 在 **测试与发布** 页面确认试聊符合预期，找到 **发布与消费者链接**。
2. 勾选 **我确认发布当前修订，并向消费者开放 AI 客服。**
3. 点击 **确认发布 AI 客服**。
4. 看到发布成功、消费者链接及二维码后，先自己打开链接，发送一条问题确认能正常回答。
5. 将该消费者链接发给客户，或点击 **下载二维码** 后使用二维码分享。

首次发布前没有消费者链接或二维码是正常状态。不能把商家后台、领取页面或网站根地址当成消费者客服链接；请使用发布后页面实际给出的、路径为 `/a/…` 的链接。

若发布按钮不能使用，查看附近提示：可能是资料尚未确认、客服被暂停、AI 服务未就绪、公开会话服务未就绪或需要重新登录。不要在页面未显示成功时宣称客服已发布。

## 七 消费者如何使用

消费者打开 H5 链接或扫描二维码，即可看到客服名称、业务简介和欢迎语。消费者不需要运营账号或商家后台密码。

在输入框输入问题，点击发送按钮与客服交流。需要开始一次新的咨询时，使用页面上的 **新建咨询**。

测试新发布版本时尤其要注意：**已有咨询继续使用创建时的版本，新咨询才使用最新发布的版本。** 如果刚修改价格并重新发布，旧对话仍按旧资料回答，不应仅据此认为发布失败；请新建咨询验证。

## 八 后续修改和日常管理

### 修改业务资料

商家工作台 → **客服草稿** → 选择目标客服并修订资料 → **保存草稿修订** → **知识库** 核对并确认新修订 → **测试与发布** 试聊 → **确认发布 AI 客服**。

保存草稿不会自动更新线上版本；修改会使旧的资料确认失效。即使页面还显示已有消费者链接，也不代表未发布的修改已经对消费者生效。

### 查看客户咨询

点击侧栏 **咨询管理**，查看当前商家的咨询列表，可按“待处理”“处理中”“已处理”筛选。查看咨询和记录跟进状态，不等于系统已经向消费者发送了人工回复；不要将它当成已接通的实时人工客服渠道。

### 平台运营者查看运行情况

- **最近商家／查找商家**：查看是否等待领取、运行中或已暂停；已开通商家可复制其管理后台链接。
- **最近客服状态**：查看草稿和已发布状态。“已发布”是版本状态，不单独证明实时对话服务健康。
- **行业模板**：维护资料收集引导，不能代替商家填写实际业务事实。
- **异常与人工处置**：核对失败任务和错误码。
- **最近审计记录**：追溯平台开通、链接重签等运营操作。

如需暂停整个商家，在对应商家项展开 **暂停商家**，填写操作原因，核对商家编号与影响并确认。暂停会阻断该商家的公开客服、已有咨询及管理访问，不是只隐藏一个客服，也不会删除资料和固定链接。恢复操作前应先确认暂停原因已经解除。

## 九 常见问题

| 情况                             | 正确处理                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------- |
| 领取链接提示无效或过期           | 先确认是否已经领取；已领取则正常登录，未领取则请运营重新签发                     |
| 打开领取页面后刷新，提示链接无效 | 从原来的完整领取链接重新打开；仍失败时联系运营，不要只复制当前已经清理过的地址栏 |
| 商家不知道以后从哪里登录         | 收藏自己的商家工作台链接；运营可在商家列表重新提供管理链接                       |
| 点击管理链接仍要求登录           | 正常；链接不是登录凭证，请用该商家授权账号登录                                   |
| 登录提示请选择有权管理的商家     | 使用目标商家的完整管理链接进入，再用已授权账号登录                               |
| 管理员密码无法登录商家后台       | 两种账号独立，商家应使用领取时的手机号和密码                                     |
| 忘记商家密码                     | 联系平台核实处理；不要重新创建商家来替代找回账号                                 |
| 没有行业模板                     | 选择手动填写；不影响文本资料创建流程                                             |
| 没有公开报价或优惠               | 明确填写“需联系商家确认”或“目前无优惠”，不要让模型猜测                           |
| 保存后没有消费者链接             | 保存与发布不同；完成资料确认、服务检查和发布后再分享                             |
| 修改后试聊仍用旧内容             | 确认已保存，并按提示重新打开当前草稿修订                                         |
| 发布后旧咨询仍回答旧价格         | 使用“新建咨询”验证最新发布版本                                                   |
| 显示服务暂不可用或请求失败       | 保留页面提示、操作时间和客服名称，交给平台排查；不要通过重复开通来解决           |

## 十 第一次体验的最短路径

如果你现在就在运营后台，下一步只做这一件事：**填写一个测试商家名称，点击“创建商家并生成领取链接”。**

随后自己领取这个测试商家，创建一个仅含几条测试资料的客服，完成确认、试聊、发布，再用手机打开消费者链接测试。第一轮不必先维护完整行业模板，也不需要配置服务器、GitHub 令牌或模型密钥。

本指南按当前发布版本的页面、按钮和已通过的 Web 验收流程编写。它不表示 WorkBuddy 已接通，也不表示受控测试环境已满足全面正式商用的运维条件。

## 十一 客服资料填写助手

这个模块帮助商家整理表达，不代替商家确认事实。支持客服名称、细分行业、业务范围、商品或服务资料、价格、优惠、欢迎语和资料不足回复。已创建客服的名称目前不提供修改入口，其他字段仍可修订。

1. 在“客服草稿”的目标字段旁点击 **帮我写**，输入简单描述。例如“纯棉毛巾 29 元一条，运费待确认，写得清楚一点”。也可从侧栏 **资料填写助手** 进入独立撰写页。
2. 字段助手会参考当前选中字段原文；独立页面仅使用简述。勾选同意把这些文字发送至阿里云千问，再点击 **生成备选文案**。
3. 比较备选和“还需要你确认”，可先编辑备选。确认商品、价格、优惠和承诺都有真实依据；未知信息保留“需商家确认”。
4. 草稿内点击 **填入此字段**；独立页面点击 **复制此文案**，然后粘贴回对应草稿字段。
5. 继续核对并点击创建或保存。填入不会自动保存、确认知识或发布。误填可以 **撤销上次填入**；若之后手动改过该字段，撤销会禁用以保护新内容。

每位商家的生成与试聊共用每分钟最多五次请求。生成失败会保留原文和简述，可以稍后重试或手动填写。独立页面切换内容类型、关闭字段助手会丢弃未使用的备选，请先复制或填入需要的文字。不要发送密码、密钥、客户隐私或未获授权资料。

## 十二 帮助中心与商家手册

商家后台侧栏的 **帮助中心** 提供任务式操作步骤：初次上手、草稿、填写助手、知识确认、试聊发布、链接分享、咨询跟进和账号排障。

输入“价格”“发布”“二维码”“登录”等关键词可查找相关主题，点击主题标题展开步骤。每篇帮助的操作按钮回到当前商家的对应页面。客服草稿、知识库、测试与发布和咨询管理也有对应的帮助链接。

点击 **下载使用手册** 可获得完整文本手册，可直接用电脑记事本打开，无需服务器操作。网页和下载内容由同一份商家帮助资料生成；使用指南和平台运营说明保存在本文件中。
