# 错误与恢复

## 总原则

- 只描述已经得到证据的状态；不把“已请求”“处理中”“未知”说成成功。
- 不因错误要求用户在聊天中发送密码、验证码、Token、`open_id` 或完整账号资料。
- 不自行生成绑定、后台或帮助链接；只使用受信服务端返回的 HTTPS URL。
- 写操作响应未知时，必须通过原幂等上下文查询结果；在结果明确前不要重复创建。
- 错误提示包含可理解原因、下一步和可供支持排查的非敏感请求/追踪 ID（若服务端返回）。

## 状态处理表

| 状态            | 用户提示                           | 允许动作                                 | 禁止动作                           |
| --------------- | ---------------------------------- | ---------------------------------------- | ---------------------------------- |
| 业务工具不可用  | 当前鉴权、数据库或生成服务尚未配置 | 按工具返回的结构化错误稍后重试或联系支持 | 模拟调用、编造链接或成功结果       |
| 未连接          | 需要在安全网页连接账号             | 打开服务端返回的 HTTPS 入口              | 在聊天索取密码、OTP、Token         |
| 授权取消/过期   | 本次授权未完成或已过期             | 重新连接                                 | 继续读取商家或后台详情             |
| 多商家待选择    | 展示已授权商家列表                 | 让用户明确选择                           | 根据名称或历史猜测                 |
| Scope 不足      | 当前账号没有所需操作权限           | 切换账号或联系商家管理员                 | 暗示资源存在、尝试越权             |
| 成员关系失效    | 当前账号已不能访问该商家           | 重新登录或联系管理员                     | 返回旧后台链接或缓存数据           |
| 当前商家无客服  | 当前商家尚未创建 AI 客服           | 进入首次生成流程                         | 返回不存在的后台地址               |
| 关键资料缺失    | 说明缺失项和影响                   | 补充、暂时跳过或取消                     | 模型自行补造事实                   |
| 行业描述过宽    | 需要一个区分信息                   | 问一个问题并给示例                       | 连续提出大量问题                   |
| 工作流过期/取消 | 原流程不能继续写入                 | 重新开始；只读查看安全摘要（若支持）     | 复活旧可写状态                     |
| 版本冲突        | 资料已在另一处更新                 | 重读最新状态并展示差异                   | 覆盖另一端修改                     |
| 确认过期        | 当前预览已变化或超时               | 展示最新预览并再次确认                   | 复用旧确认                         |
| 创建处理中      | 请求已受理但尚未完成               | 查询真实进度                             | 宣称草稿已创建                     |
| 创建部分失败    | 说明真实已保存内容和失败项         | 使用服务端提供的安全重试动作             | 返回虚假完整结果                   |
| 超时/响应未知   | 暂时无法确认结果                   | 用原幂等上下文查询                       | 立即重复创建或断言失败/成功        |
| 限流            | 请求过于频繁                       | 按服务端建议稍后重试                     | 无界重试                           |
| 服务不可用      | 平台暂时不可用                     | 保留非敏感进度并稍后重试                 | 降级为无鉴权操作                   |
| 链接不可用      | 当前没有可验证的安全链接           | 回到连接状态检查或联系支持               | 拼接、猜测或采用用户提供的登录链接 |

## 推荐回复结构

```text
当前状态：<真实状态>
发生了什么：<不泄露内部资源与身份的简短说明>
你的资料：<已保存 / 未提交 / 无法确认，以服务端结果为准>
下一步：<一个主要恢复动作>
排查编号：<服务端返回时才显示非敏感 ID>
```

## 典型恢复示例

授权过期：

> 当前连接已过期。请通过安全网页重新连接；不要在聊天中发送密码、短信验证码或访问令牌。完成后可以继续当前步骤。

创建响应未知：

> 请求结果暂时无法确认，我不会重复创建或声称已经成功。接下来会用原请求上下文查询真实状态；你的已有线上客服不会因此自动变化。

版本冲突：

> 这份资料已在另一处更新。我会先读取最新版本并展示差异，不会覆盖对方的修改。确认新预览后才能再次创建草稿。

用户要求直接发布：

> 当前流程只创建可编辑草稿，不执行发布。创建成功后你可以进入后台核对；发布需要单独的权限检查、预览和明确确认。
