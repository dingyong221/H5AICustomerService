# 当前 Web 操作和资料约束

## 先区分链接

首次领取链接只用于建立负责人账号；长期管理链接属于一个独立商家；消费者链接由发布页实际给出，路径为 `/a/…`。管理地址不携带访问权限，用户改写商家 ID 不能绕过成员校验。

同一手机号已存在账号时，应在安全网页用原密码领取另一个有权管理的商家，不能在聊天中验证密码或自动合并其他人账号。通用登录页目前没有多商家选择器，账号关联多个商家时使用目标商家专属链接。

## 创建和使用

1. 运营开通商家，实际负责人用一次性领取链接在安全网页设置或验证自己的账号。
2. 登录商家后台，打开“客服草稿”。电商零售预设是通用购物咨询说明，仍需实际商品、价格与交易规则。
3. 填写全部字段并点击“创建客服草稿”。看到成功结果和客服入口后，才能说草稿已创建。
4. 进入“知识库”核对当前草稿修订，点击“确认当前草稿资料”。这不是发布。
5. 打开“测试与发布”先试聊。试聊用已保存的草稿；把测试资料发送至千问前阅读平台提示并确认资料授权。
6. 对回答不准确的地方先修改、保存、重新打开最新修订并确认。点击单独的发布确认才对消费者开放。
7. 发布后复制页面实际提供的消费者链接或下载二维码，打开链接新建咨询验证。旧会话保持建立时版本。

“帮我写”只把简述和当前字段原文发送至千问生成备选，需勾选发送确认。选择填入后尚未保存，可撤销；再手动编辑过该字段时不能用撤销覆盖新文字。独立填写助手可复制文案。

## 字段约束

| 字段             | 最大字数 |
| ---------------- | -------- |
| 客服名称         | 200      |
| 细分行业         | 128      |
| 业务范围         | 2000     |
| 商品或服务资料   | 4000     |
| 价格与条件       | 4000     |
| 优惠与售卖策略   | 4000     |
| 欢迎语           | 500      |
| 资料不足时的回复 | 500      |

目前没有文件或 JSON 自动导入，没有商家自助多门店编排，也没有实时人工聊天台。咨询管理用于查看对话和记录跟进状态；商家如需暂停服务，联系运营。帮助中心可以搜索步骤、下载完整文本手册。

忘记密码、领取链接失效或账号归属错误时联系运营核实。创建、试聊或发布失败按页面错误操作，不要为了重试重复开通商家，不承诺未经服务器保存的进度可跨任务恢复。
